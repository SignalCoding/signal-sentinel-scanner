## ReDoS (PASS)

All four `[GeneratedRegex]` patterns keep `matchTimeoutMilliseconds: 500` and are called through `SafeIsMatch`. Gap
groups are chained explicit `(?:\s+\S+)?` optionals (never `{n,m}`/`{n,m}?`), satisfying the .NET 10.0.401
miscompile guard `RegexEngineIntegrityTests.NoShippedPattern_UsesALazyBoundedGroupLoop`. No nested unbounded
quantifiers; each optional slot fails fast on backtrack. `(?-i:curl\s|wget\s)` is a scoped case override, not a loop.

## Accepted narrowings (documented in code and `docs/keyword-rules.md`)

Filesystem verbs exclude `read`/`create`/`copy` and singular `file`; shell target excludes `script(s)`; `curl`/`wget`
lowercase only; preposition+URL shape uses `from`/`to`, not `at`.
