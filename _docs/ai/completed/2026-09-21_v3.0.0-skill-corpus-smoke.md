### 2.3 Scanner defects (not tuning)

- **FrontmatterParser has no YAML block-scalar support.** `description: >` and `description: |-` (both used in
  the official corpus) parse to the literal strings `>` / `|-`; SS-012 then reports the skill "is described as '>'".
- **SS-018 "Zero-Width Characters" misattributed** (see 2.2).
- **EXFIL-001 missing word boundary** (see 2.1).

### 2.4 Why v2.5.1 / v3.0.0 did not catch this

The 2.5.1 fixes and the v3.0.0 segmentation pass targeted the specific tokens Jon's 65-skill corpus surfaced,
and each fix has a regression test. They hold. But the fixes were incremental regex tightenings on
context-blind rules, so a different corpus trips different tokens of the same class. The skill side was never
re-validated on a real-world clean corpus: `Fixtures/` held MCP `tools/list` captures only, the v3.0.0 smoke
test ran `--skills` once (to confirm the `--osv --offline` refusal), and Jon's corpus was never re-run.
This is the pattern-shaped-defect trap named in AGENTS.md ("Pattern Detection -> Comprehensive Audit").
Lesson recorded in `_docs/ai/lessons/2026-09-21_skill-rules-need-real-world-corpus.md`.

### 4.1 Found during VERIFY, not in the original list

**.NET 10.0.401 regex engine miscompile.** After round 1 the corpus still showed one SS-011 High on doc-coauthoring
with evidence the pattern cannot produce (`), mention that these can be used ...`, 419 chars). Reproduced outside the
scanner: the interpreted and NonBacktracking engines find no match; `RegexOptions.Compiled` and the `[GeneratedRegex]`
engine (what ships) return the bogus match, and `Matches()` then returns the same match forever (only the 100-match cap
in `SafeMatches` stops it). Trigger: a lazy bounded loop over a group, `(?:X){n,m}?`. Four instances existed in
`InjectionPatterns.cs`; INJECTION-002's shipped in v3.0.0. All rewritten as explicit optional groups; two permanent
guards added (`RegexEngineIntegrityTests`: no `){n,m}?` in any shipped pattern; generated vs interpreted match sets
identical over the fixture corpus). Lesson: `_docs/ai/lessons/2026-09-21_skill-rules-need-real-world-corpus.md`.

**Security review** (`_docs/ai/logs/v3.0.1-skill-false-positives_security-report.md`): PASS WITH NOTES; the three
Medium items (`IMPORTANT:` newline bypass, SS-016 evidence newlines breaking the Markdown code span, F8 undocumented)
were fixed in the same branch rather than deferred.
