# Coauthor

Keep one draft. Work in passes.

1. Agree the outline with the user before writing any section.
2. Draft one section at a time and read it back.
3. Record every accepted change in the draft itself, not in chat.

## Gathering source material

**Check for connected integrations** (Google Drive, Notion, Confluence, SharePoint, or other MCP servers), mention that these can be used to pull in context directly.

Ask the user to name the source documents before you draft anything. A shared outline is worth more than a fast first draft.

- If no integrations available: Ask the user to paste the relevant passages
- If integrations available: Inform them the content will be read now, then use the appropriate integration
